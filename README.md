# Bedayat Studios — Website Department

Bedayat Studios creates websites for businesses. This repository is the website department’s workspace for building client websites and preparing website demos.

## What we do

We design and build websites that help businesses present their work, explain their services, and connect with customers online. Bedayat Studios also works on ads, posters, and menus; this repository focuses on the website side of the business.

## Repository layout

- `Websites/` — website projects for clients. The current project here is `Rou2a`.
- `Website demos/` — demo and concept websites, including `Mare` and `Pocket Moon Coffee`.

## Working with a project

Each website may use its own files and technologies. Open the relevant project folder and check its files for project-specific details and instructions. Static HTML demos can be opened directly in a browser; other projects may have their own setup requirements.

## Adding a website

1. Create or place the project in the appropriate folder.
2. Keep each client or demo in its own clearly named directory.
3. Include any project-specific setup notes with that project.
4. Avoid putting private client information, credentials, or secrets in the repository.
